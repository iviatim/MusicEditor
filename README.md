# Music Framework — цифровая обработка музыки с использованием нейросетей

Модульный фреймворк для разделения источников звука, семантических преобразований и постобработки аудио. Разработан как выпускная квалификационная работа (ВКР) по направлению «Прикладная информатика» в СПбПУ Петра Великого.

## Возможности

- **Разделение источников звука** на 4 стема: вокал, барабаны, бас, остальные инструменты (нейросеть Demucs, htdemucs).
- **Семантическое разделение вокала** на ведущий и фоновый на основе Mid-Side анализа — собственное новшество, которого нет у коммерческих аналогов (Vocalremover, Moises.ai, Lalal.ai).
- **Постобработка артефактов**: спектральное вычитание, гейтирование, частотная коррекция вокала.
- **Семантические преобразования**: изменение темпа и тональности независимо друг от друга (Rubber Band).
- **Аугментация данных** для дообучения моделей (Audiomentations).
- **Оценка качества разделения** по метрикам SDR, SAR, SIR (TorchMetrics, mir_eval).
- **Веб-интерфейс** на Gradio: загрузка трека, разделение, прослушивание, скачивание результатов.
- **Docker-контейнеризация** для развёртывания одной командой.

## Стек

- **Язык:** Python 3.11
- **Глубокое обучение:** PyTorch 2.0, Demucs (htdemucs)
- **Аудио:** Librosa, SoundFile, Pyrubberband, TorchAudio, noisereduce
- **Метрики:** TorchMetrics, mir_eval
- **Аугментация:** Audiomentations
- **Интерфейс:** Gradio
- **Тестирование:** Pytest
- **Контейнеризация:** Docker
- **Облако:** Yandex Cloud (для апробации)

## Архитектура

Фреймворк построен по принципу разделения ответственности и состоит из независимых модулей:

| Модуль | Назначение |
|---|---|
| Ядро (core) | Ввод/вывод аудио, ресемплинг, спектральный анализ |
| DemucsSeparator | Интеграция нейросети Demucs, разделение на стемы, сегментация длинных треков |
| SemanticTransformer | Изменение темпа и тональности через Rubber Band |
| AugmentationPipeline | Аугментация данных (шум, сдвиг, изменение темпа) |
| SeparationMetrics | Расчёт SDR, SAR, SIR |
| Gradio UI | Браузерный интерфейс |
| Docker | Контейнеризация и развёртывание |
